# Kit: Expediciones de Ashenfall

1. Descomprime esta carpeta y ábrela en Claude Code.
2. Pega el contenido de `PROMPT-PARA-CLAUDE-CODE.md`.

| Carpeta / archivo | Qué es |
|---|---|
| `PROMPT-PARA-CLAUDE-CODE.md` | El prompt listo para pegar |
| `SPEC.md` | Especificación técnica: API de MetaForge, tiles, fórmula de coordenadas, algoritmo, chat, problemas conocidos |
| `data/expeditions.json` | 25 expediciones y 560 paradas, limpias y con link a MetaForge |
| `data/knowledge-base.md` | Guía del juego para el chat (misiones, vaults, Dowdun, recetas) |
| `data/pins-*.txt` | Pines crudos de MetaForge (PL1–5 y Dowdun) |
| `assets/*.webp` | Mapa del mundo (z5) y Dowdun subterráneo (z6), ya cosidos |
| `reference/expediciones-v4.html` | La versión actual que funciona, de un solo archivo |
| `scripts/*.py` | Scripts originales de clustering y rutas |
